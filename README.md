# NEXO ENEM

Plataforma de estudos para o ENEM com interface futurista e responsiva.

## Já implementado

- Dashboard no visual NEXO ENEM
- Modo claro e escuro
- 500 questões geradas em 4 áreas, com ciclo sem repetição
- Filtros por área, matéria e dificuldade
- Treino adaptativo baseado nos temas com mais erros
- Histórico e gráficos de desempenho
- Laboratório de redação com análise estimada pelas 5 competências
- Tela animada durante a análise da redação
- Temas de redação
- Videoaulas
- Feedback
- Ranking
- Área administrativa
- Persistência local no navegador
- Cabeçalhos de segurança para Cloudflare

## Deploy

O projeto foi preparado para deploy estático direto pelo Cloudflare Pages a partir da branch `main`.

Build command: deixe vazio.

Output directory: `/` (raiz do repositório).
